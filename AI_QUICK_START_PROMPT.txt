สวัสดีครับ! คุณคือ AI ผู้ช่วยพัฒนาโปรเจกต์ "ตู้ชาร์จโทรศัพท์มือถืออัจฉริยะ 4 ช่อง (Smart USB Charger)" ของคณะผู้จัดทำโครงงาน ชั้น ม.3/13

สถาปัตยกรรมและมาตรฐานความปลอดภัยปัจจุบันของโปรเจกต์:
1. ฮาร์ดแวร์: บอร์ด DOIT ESP32 DEVKIT V1 ควบคุม 4-Channel Relay (Active-High):
   - พอร์ต 1: USB-A 1 (GPIO 26), พอร์ต 2: USB-A 2 (GPIO 27), พอร์ต 3: USB-C 1 (GPIO 25), พอร์ต 4: USB-C 2 (GPIO 33)
   - เมื่อเปิดเครื่องต้องตั้งรีเลย์ทั้งหมดเป็น LOW ก่อนเชื่อมต่อ Wi-Fi และมีตัวจับเวลา Fail-Safe ตัดไฟอัตโนมัติในบอร์ด
   - ส่งรหัสยืนยัน ESP32 ผ่าน HTTP Header `X-ESP32-Secret` เท่านั้น และตั้งค่าผ่าน Smart Wi-Fi Captive Portal (`192.168.4.1`)
2. เซิร์ฟเวอร์ Backend (`charging-server.js` บน Render: https://usb-charger.onrender.com):
   - เป็น Single Source of Truth ควบคุมสถานะพอร์ต, เวลาถอยหลัง, Anti-Collision Hold, Visitor Stats (`VIS-`/`USR-`), ประวัติธุรกรรม (`TX-`) แบบระบุผู้จ่าย->ผู้รับ, Audit Logs (`AUD-`), และคิวตรวจสลิปด้วยมือ (`PEN-`)
   - ยกเลิกระบบ PIN/รหัสผ่านแอดมินทั้งหมด ใช้ Google Sign-In (Firebase ID Token + `admin_whitelist` / ENV `ADMIN_EMAILS`) เท่านั้น
3. หน้าเว็บ Frontend (Firebase Hosting: https://usb-charger-project.web.app):
   - `public/index.html`: หน้าตู้ชาร์จ Modern Kiosk + Tracking ID (`USR-`/`VIS-`) + ป้องกันการจ่ายซ้อน + แสดงสถานะรอตรวจสลิป (HTTP 202)
   - `public/admin.html`: แดชบอร์ดแอดมิน Google Auth, คิวอนุมัติสลิป, ประวัติผู้เข้าชมและผู้จ่าย/ผู้รับ, Audit Log, และตั้งค่าบัญชีรับเงิน/ราคา
4. ความปลอดภัย:
   - ห้ามใส่รหัสผ่าน, PIN, API Keys, เลขบัญชี, หรือเบอร์โทรจริงลงในโค้ดหรือเอกสาร ให้ตั้งค่าผ่าน Render Environment Variables หรือหน้า Admin Settings เท่านั้น

โปรดอ่าน `PROJECT_MEMORY.md` และ `.gemini/GEMINI.md` เพื่อทำความเข้าใจรายละเอียดทั้งหมดก่อนเริ่มแก้ไขโค้ดครับ!
